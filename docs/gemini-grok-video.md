# תמונות ווידאו מג'מיני וגרוק (בדפדפן של סתיו)

## תמונות
- כל פרויקט בשיחה אחת עם תמונות הייחוס בראש השיחה. כל סצנה = הודעה חדשה באותה שיחה.
- שליחה: למקד את `rich-textarea .ql-editor`, ואז `document.execCommand('insertText', false, text)` ו-Enter.
- העלאת קבצים לשיחה חדשה: לעקוף את `HTMLInputElement.prototype.click` כדי לתפוס את שדה הקובץ, ללחוץ "העלאה וכלים" ← "העלאת קבצים", ואז file_upload לשדה שנתפס (עד 10MB).
- הורדה: canvas.drawImage של התמונה של התשובה הרצויה ← toBlob ← a.download. התמונות נוחתות בהורדות (לפעמים בתת-תיקייה). לא להוריד יותר מתמונה אחת בכל 2 שניות — הכרום חוסם הורדות מרובות.
- תמונות של ג'מיני יוצאות 1024x572 ב-16:9. להגדיל לפני רינדור.
- שיחות קבועות: סתיו 53a9d223a159b17d, אור e89373bde548e3a2, קליפ "אהובתי" e4473ba683a91d44.

## וידאו מתמונה
- ג'מיני: "+" ← "יצירת סרטון" ← הדבקת תמונה ← יחס "לאורך" ל-9:16. כל סרטון בשיחה חדשה, אחרת הוא ממשיך סרטון קודם.
- כשנגמרת המכסה של ג'מיני: grok.com/imagine, אותה שיטה.
- להנפיש רק סצנות עם דמות אחת. בסצנות עם כמה דמויות הפנים נודדות.
