## כללים קבועים (לכל הסרטונים)
- קריינות בעברית: הטקסט המוקרא תמיד עם ניקוד מלא. הכתוביות בלי ניקוד.
- קליפים לשירים: האודיו המקורי מ-Suno, כתוביות בשפת השיר, החתימה stavjadam, וחייבים לזוז — לא מצגת תמונות.
- הדמות של סתיו: כובע קסקט, משקפיים עגולים שחורים, שיער אפור ארוך מתולתל, זקן אפור בסנטר, **בלי שפם**, עגיל.
- אור: שיער אדום גלי, משקפיים חומים, נמשים, מלאה ועגולה. תמונת ייחוס אמיתית — לא ניחוש.
- כל סרטון נבדק לפני מסירה: כמה פריימים, סאונד וכתוביות.

## מתי לעבוד עם Claude באפליקציה, ומתי עם Claude Code

**Claude באפליקציה (השיחה הרגילה) — רוב העבודה:**
- כל מה שצריך דפדפן: ג'מיני לתמונות ולווידאו, פייסבוק, יוטיוב, דיסטרוקיד.
- כל מה שצריך את המחשב שלך: תיקיות, הורדות, שמירת קליפים במוזיקה.
- מסד הנתונים, מיילים, משימות מתוזמנות, כתבות, חבילות.
- גם בניית קליפים ורינדור — יש כאן מחשב בענן עם כל הכלים.

**Claude Code — כשהעבודה היא קוד גדול במאגר:**
- שינויים באתר עצמו (`masterphub-site`): עמודים חדשים, באגים, פיצ'רים. במקום Replit Agent, שאוכל את התקציב.
- שינוי עמוק במנוע הסרטונים האוטומטי (`engine/`), כשצריך לבדוק ולהריץ הרבה פעמים.
- הסשן "Montage" בשרת (OpenMontage).

כלל אצבע: אם התוצאה היא **קוד שנכנס למאגר** — Claude Code. אם התוצאה היא **תוכן, פרסום או פעולה בעולם** — כאן.
