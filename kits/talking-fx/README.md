# talking-fx: אפקטים על קליפ אמיתי של סתיו מדבר

קליפ מהטלפון נכנס, סרטון ערוך יוצא. הדמות מופרדת מהרקע על המחשב (בלי API ובלי תשלום), כך שגרפיקה יכולה לשבת מאחוריו.
נבדק 19.10.26 במחשב בענן של Claude: עובד, בערך 0.6 שניות לפריים (קליפ של 10 שניות ≈ 3 דקות).

## איך
1. `bash prep.sh clip.mp4 work` מכין את work/: video.mp4 (אנכי 1080x1920), person.webm (הדמות בלי רקע), index.html עם האורך.
2. עורכים את work/index.html: שכבה 2 (#fx) לגרפיקה מאחור, שכבה 4 (#front) לגרפיקה מלפנים. הדוגמה היא שם ענק מאחורי הראש.
3. `cd work && npx -y hyperframes render . -o final.mp4`
4. בדיקה לפני מסירה: `npx hyperframes snapshot` או חילוץ 5 פריימים ב-ffmpeg. הפנים והידיים אטומות ולא מכוסות, הסאונד המקורי קיים.

## אפקטים מוכנים
עשרת הפרומפטים בחבילה "Video Effects with Claude Code" (masterphub.io/packs/claude-code-video-effects, טבלת prompts מזהים 517279 עד 517288):
מסלול פוסטים, שער מגזין, ורטיגו, קו מצויר ושרבוטים, קיר תגובות, קולאז' נייר, אותיות זכוכית, קו חי, צ'אט שמקליד, כתוביות מילה אחרי מילה.
